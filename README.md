# 🚢 Titanic Data Analysis

A data analysis project exploring 
survival patterns of the Titanic 
disaster using Python and Pandas.

## 📊 Dataset
- Source: Kaggle Titanic Dataset
- 891 passengers
- 12 features including age, 
  gender, class and survival

## 🔍 Key Findings

### Survival Rate
- Total survived: 342 (38.38%)
- Total died: 549 (61.62%)

### Gender Impact
- Female survival rate: 74.20%
- Male survival rate: 18.89%
- Women survived 4x more than men

### Class Impact
- 1st Class survival: 62.96%
- 2nd Class survival: 47.28%
- 3rd Class survival: 24.24%
- Rich passengers survived 2.5x 
  more than poor passengers

### Age Impact
- Youngest passenger: 0.4 years
- Oldest passenger: 80 years
- Avg age survivors: 28.55
- Avg age non-survivors: 30.42

## 🛠️ Data Cleaning
- Filled missing Age values 
  with mean age
- Dropped Cabin column 
  (77% missing)
- Filled missing Embarked 
  with most common port

## 💻 Technologies Used
- Python
- Pandas
- NumPy
- Google Colab
